# Oxford FIXR Halloween pilot — 24 October to 1 November 2026

The app contains 84 single-date event listings from FIXR's [Oxford city pages](https://fixr.co/cities/oxford), covering 24 October through 1 November. The records in [`app/src/data/oxfordFixrEvents.ts`](../app/src/data/oxfordFixrEvents.ts) have the displayed title, venue, date, direct FIXR URL, FIXR-hosted organiser image URL, short description excerpt and availability snapshot. The event detail pages supplied exact start and finish times for 83 records. One Scary Sessions listing lacked usable timing; it expires after 31 October in the Europe/London calendar. The other events disappear from the app after their published end instant, including events that run past midnight.

This is a dated test snapshot, not a live feed. Some recurring multi-date course listings on the same city pages were excluded because the specific ticket/session date was unclear. The already-finished 23 October event was excluded. Matching names can represent distinct FIXR event IDs; keep the exact ID and date when attaching a seller ticket. Availability may change, and a sold-out FIXR listing does not itself prove a ticket can be transferred. The app links to FIXR for the complete organiser description, live availability, age rules and transfer eligibility.

The app loads event posters from FIXR's CDN and credits FIXR/the organiser. It does not copy those posters into the repository.

This is a one-time public-page research snapshot. FIXR's [customer terms](https://fixr.co/legal/customer-terms-and-conditions) prohibit scraping/crawling and commercial reuse of platform content. The new [catalogue importer](../backend/README.md) therefore accepts a rights-confirmed feed instead of scraping FIXR pages. Once a permitted feed and persistent server are configured, it imports daily, tracks venues and recurring series, and supplies new events to the app. Until then, the existing snapshot remains the fallback and new FIXR events do not appear automatically. The app's local screenshot preview is not an upload to a server; no public listing or checkout is live. Inbox checking is available as an operator tool once the Gmail inbox is set up ([setup](fixr-inbox-setup.md)).
